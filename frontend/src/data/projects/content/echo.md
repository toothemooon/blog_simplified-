# ECHO

ECHO is an offline-first iOS quote experience designed around calm reading,
thoughtful personalization, reliable attribution, and tactile visual themes.

## What's New in Build 7

### Author Biography Pages
Each author now has a dedicated biography page featuring:
- **Life Summary**: Concise biographical information covering key periods and achievements
- **ECHOS**: Highlighted moments that capture the essence of each author's contribution
- Available in English, Simplified Chinese, and Japanese

### Accessibility Support
ECHO now includes comprehensive accessibility features:
- Dynamic Type support for system font size preferences
- VoiceOver compatibility throughout the app
- High contrast mode support
- Reduced motion options for users with vestibular sensitivities

### Refined Typography
Quote text has undergone multiple rounds of professional proofreading:
- Verified translations across all three languages
- Consistent punctuation and formatting
- Improved readability for longer passages

## Core Features

- **Offline-First Design**: All quotes, bookmarks, and preferences stored locally
- **Three Visual Themes**: Light, Dark, and textured Archive theme
- **Smart Recommendations**: Preference-based quote suggestions
- **Bookmark System**: Save and organize your favorite quotes
- **Share Cards**: Generate beautiful quote images for social sharing
- **Multi-Language Support**: English, Simplified Chinese, and Japanese

## Technical Details

The current MVP is distributed as a free TestFlight build and does not include
advertising, subscriptions, paid unlocks, accounts, or cloud synchronization.
